1. nodemon (auto save when build a web)
```
npm i nodemon --save-dev
```

2. json file:
```
"scripts": {
    "start": "nodemon index.js",
  },

-> npm start
```

3. morgan
```
npm i morgan --save-dev 
```

4. Template engine (handlebars)
```
npm install express-handlebars
```

5. Run
```
npm start
npm run watch
```
